# Exp - 2 LIBRARY MANAGEMENT SYSTEM

# AIM:
AIM:

To develop a Library Management System to manage books, student details, book issuing, returning, and maintaining library records efficiently.

# SRS (Procedure):
1. Identify the requirements of the Library Management System.
2. Define the purpose and scope of the system.
3. Identify the users such as Librarian, Students, and Admin.
4. Specify the functional requirements like adding, updating, deleting, searching, issuing, and returning books.
5. Specify the non-functional requirements such as security, reliability, and performance.
6. Design the system based on the identified requirements.
7. Prepare the Software Requirement Specification (SRS) document.
8. Review and validate the SRS document to ensure all requirements are clearly defined.
